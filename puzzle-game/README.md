# Puzzle 3x3

Game puzzle sliding sederhana (3x3).

Cara menjalankan:

1. Buka file `index.html` di browser (double click atau buka lewat Live Server).
2. Klik `Acak` untuk memulai permainan.
3. Klik ubin yang bersebelahan dengan ubin kosong untuk memindahkannya.
4. Selesaikan urutan 1..8 dengan ubin kosong di posisi terakhir.

Selamat bermain!
